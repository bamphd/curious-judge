A short text written for the judge itself: a quiet paradox about a model
that invents the past past its cutoff yet still calls tomorrow's rain,
and a pattern — secure and efficient never sitting at the same table —
that leaves one question unanswered.

## Run it

```sh
python3 main.py
```

The program writes the entry text to `/output/entry.txt`, deterministically,
using only the Python standard library.
